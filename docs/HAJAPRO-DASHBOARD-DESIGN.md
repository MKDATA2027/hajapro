# HAJAPRO Dashboard Design Reference

Approved by the user on 2026-10-22. Use the user's MK Hausa Dictionary color reference and the generated HAJAPRO dashboard mockup in the conversation as the visual direction.

## Mandatory palette
- White background everywhere in the dashboard: #FFFFFF
- Primary emerald green for buttons and interactive icons: #087F5B
- Dark teal for headings, branding and navigation accents: #0B3332
- Soft mint for subtle icon/card fills: #EAF5F0
- Gold as a restrained decorative accent only: #D5A64A
- Muted text: #526765
- Borders: #DCE8E4

## Rules
- Do not use dark/navy dashboard backgrounds or gradients.
- Main cards and shortcut tiles remain white with subtle pale green borders and restrained shadows.
- Primary buttons use emerald green with white text.
- Headings and key navigation accents use dark teal.
- Icons are emerald on pale mint; gold is reserved for occasional small highlights (e.g. AI accent).
- Preserve HAJAPRO's existing module names, interactions, compact two-column mobile-first tile layout, wallet behavior and language-aware “Biyan Kuɗi” / “Payment” label.
- Do not replace or redesign the approved HAJAPRO logo.
- This file is the persistent project design reference; consult it before future dashboard color changes.
